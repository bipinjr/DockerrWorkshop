DockerrWorkshop

LangChain agent tool packaged as a Docker container

What this service does

A FastAPI backend that exposes a weather agent tool over HTTP. The tool uses a Pydantic input schema for validation and reads its API key from an environment variable (never hardcoded).

Endpoints

GET /
POST /weather

GET / returns {"status":"ok"} — health check
POST /weather accepts {"city":"London"} and returns weather info

Run locally

  • python3 -m venv .venv && source .venv/bin/activate
  • pip install -r requirements.txt
  • python3 main.py
  • curl http://localhost:8000

Docker

  • docker build -t my-agent:latest .
  • docker run -p 8000:8000 --env-file .env my-agent:latest
  • curl http://localhost:8000

Deploy to cloud

  • Push this repo to GitHub
  • Connect it to Render or Railway
  • Set WEATHER_API_KEY in the platform dashboard
  • Deploy — you'll get a live URL
